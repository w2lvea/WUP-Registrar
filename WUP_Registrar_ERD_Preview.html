💡 DIAGRAM GUIDE
How to read relationships & symbols
PK Primary Key
Unique identifier for each record in the table
FK Foreign Key
Connects this record to another table
1 : Many (1:N)
1 Student can submit Many Requests; 1 Request has Many Items
1 : 1 (Single-use)
1 Official Receipt can only be used by 1 Request
Solid Line ➔
Direct database relationship (Parent to Child)
Dashed Line ⇢
Catalog reference or lookup validation
